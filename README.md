# Privet AI

An AI-powered Russian course for English speakers. Every lesson follows a closed loop —
**Teach → Drill → Recall → Use → Review** — so new words get practised, produced, used in
context and then scheduled for spaced repetition, not just seen once.

## What's in the app

- **Learn** — a 25-lesson A1 path across five units (alphabet → introductions → cases →
  motion verbs → past tense and aspect). Each lesson is generated by OpenAI from a brief in
  `src/data/courseContent.ts`, then cached on the device so replays are instant and free.
- **Practice** — flashcard decks reviewed with SM-2 spaced repetition. Words from finished
  lessons are added automatically; you can also generate a deck on any topic.
- **AI Tutor** — roleplay conversations (café, directions, market…) and custom lessons on
  any topic.
- **Profile** — streak, XP, lessons completed, words learned and the grammar areas you
  make the most mistakes in.

The teaching rules the AI must follow live in `ApplicationRules.md`,
`LearningGuidelines.md` and `UIDesignGuidelines.md`; the generator prompt is in
`src/lib/prompts.ts`.

## AI provider and API keys

The app runs entirely in the browser and calls the AI provider directly with **the learner's own
key**, entered in onboarding or Settings and stored only in that browser's local storage.

- **Claude** (Anthropic, `claude-opus-5-5`) or **OpenAI** (`gpt-4o-mini`) writes lessons, runs
  roleplay, checks answers and explains mistakes — pick one in Settings. Models are set in
  `src/config.ts`; all text generation goes through `src/lib/ai.ts`.
- **Voice answers** (Whisper) and **OpenAI voices** need an OpenAI key, since Claude has no speech
  APIs. Without one, the mic is hidden and the browser's built-in voices read Russian aloud.

**Never put an API key in the source code.** The site is deployed as static files, so anything
in the bundle is public.

## Development

```bash
npm install
npm run dev        # http://localhost:5173/Privet-AI/
npm run typecheck
npm run lint
npm run build      # typecheck + production build into dist/
npm run deploy     # build and publish dist/ to GitHub Pages
```

Mobile and desktop shells: `android/` and `ios/` (Capacitor) and `src-tauri/` (Tauri).

## Project layout

| Path | What it holds |
| --- | --- |
| `src/pages/` | Routed screens: Home (path), Lessons, Practice, Roleplay, Profile, Settings, Onboarding |
| `src/components/LessonModules.tsx` | Vocabulary, grammar, drill and dialogue steps |
| `src/components/RecallView.tsx` | Typed/spoken production step |
| `src/lib/lessonParser.ts` | Turns the generator's JSON into lesson steps |
| `src/lib/answerValidation.ts` | Deterministic answer checking (stress marks, ё/е, punctuation) |
| `src/lib/srs.ts` | SM-2 scheduling |
| `src/store.ts` | Persisted app state (Zustand) |
| `src/config.ts` | Model names |
